ERD 초안 일단 업무분석서 기준으로 만들어봤습니다!

파일은 `erd.mwb`(Workbench), `erd.png`(그림), `erd-draft.sql`(테이블 정의)로 올려둘게요.  
테이블은 총 17개이고, 초록색 테이블은 약품/금기/진찰료처럼 관리자가 등록해서 사용하는 데이터입니다.

제가 일단 전체적으로 초안을 만들어둔 거라서 다 같이 처음부터 보실 필요는 없고, 각자 아래 부분 정도만 가볍게 봐주시면 될 것 같습니다!  
보시다가 관계나 속성 중에 이상한 부분이나 바꾸면 좋을 것 같은 부분 있으면 편하게 말씀해주세요. 따로 없으면 이상 없다고만 남겨주셔도 됩니다!

**서희님**
- 사용자계정 / 환자 / 진료과 / 의사 / 의사일정 / 예약 쪽
- 특히 환자 중복가입 기준이나 예약 중복 처리 방식 정도 봐주시면 될 것 같습니다.

**준모님**
- 접수 / 진료기록 / 결제 / 진찰료 쪽
- 접수에서 예약 정보를 통해 환자·의사를 가져오는 구조나 결제/진찰료 연결 부분 정도 봐주시면 됩니다.

**윤재님**
- 처방 / 처방상세 / 약품 / 병용금기 / 연령금기 쪽
- 약품이랑 금기 관계, 처방 금기 기록 방식 정도 확인해주시면 될 것 같습니다.


업무분석서 기준으로 최대한 맞춰서 작성했는데 제가 놓친 부분이 있을 수도 있어서 각자 맡은 쪽만 한 번씩 확인 부탁드립니다!

확인해주시면 전체 ERD 초안 작성 및 Workbench 정리, 의견 주신 부분 반영해서 최종본 정리해서 한번 더 확인 받고 출력해서 팀미팅때 가져가겠습니다!
